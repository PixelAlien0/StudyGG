# Computer Networks I — Study Room

A zero-dependency study website generated from **Chapter 11 Computer Networks I.pptx**.

## Open it

From this folder, run:

```powershell
npm run dev
```

Then open `http://127.0.0.1:4173`.

You can also open `index.html` directly, although the local server gives the most consistent PDF and browser behavior.

## Included

- 113 source-slide notes and images
- 183 curated Q&A cards
- 157 curated multiple-choice questions
- Five chapter modules
- Search, module filtering, slide bookmarks, local progress, review pile, and mistake-only drills
- A complete PDF copy of the source deck
- Locally vendored GSAP 3.15.0 motion and ScrollTrigger reveals, with reduced-motion support

Every answer is supported by a specific PPT line. Multiple-choice options are cleaned of source list labels such as `A)`, `C.`, and `3.` while preserving the teacher's wording and keywords.
